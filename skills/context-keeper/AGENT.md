# ContextKeeper：通用 Agent 入口

此目录是自包含能力包，可供支持 Agent Skills 的宿主加载，也可由普通编码 Agent 直接读取。无需 Codex、MCP、数据库或后台服务。

1. 先读取同目录的 [SKILL.md](SKILL.md)，按用户当前请求选择保存、恢复或经验流程。
2. 将 SKILL.md 中的 `<skill-dir>` 替换为本目录的绝对路径；`<project>` 是用户指定的代码项目。
3. Python 脚本位于 `scripts/ck.py`，依赖 Python 3.9+ 标准库；Git 用于完整工作区核对。
4. 不支持原生 Skill 发现时，用户可显式让 Agent 读取本文件。此文件不是宿主自动发现机制，也不会授予执行权限。
5. 若只能对话、不能读本地文件或执行脚本，可让用户提供项目的 HANDOFF.md，按其内容继续讨论；不能声称已做脚本核对或已保存文件。

完整使用需要能力包与目标项目在 Agent 可访问的环境中。安装能力包不自动传输其他 Agent 的对话、代码或私有项目上下文。
